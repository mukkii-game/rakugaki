# rakugaki

## 編み図3Dビューア

編み図を1段ずつ記号で書くと、編み上がりの形を three.js で立体表示するウェブアプリです。

```
python3 -m http.server 8000   # → http://localhost:8000/
```
（ES モジュールを使うので `file://` で直接開くのではなく、ローカルサーバー経由で開いてください）

### 記法（1行＝1段）
| 記号 | 意味 |
|---|---|
| `×` | 細編み |
| `T` / `F` | 中長編み / 長編み |
| `V` / `W` | 2目・3目編み入れ（増し目） |
| `Λ`（`A`） | 2目一度（減目） |
| `×6`, `(× V)*6` | くり返し |
| `#rrggbb` | その段の色 |

前段の目数と合わない段は警告を表示します。
